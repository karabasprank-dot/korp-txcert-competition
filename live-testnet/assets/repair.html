What a valid plan means

        

          Blocked: no unwanted supplied permit can execute in
          any reachable order of the supplied permits. Slots explicitly marked
          clear must have stored allowance zero, including after any reachable
          known grant. These are separate requirements.
        

        

          Preserved: the specified wanted permission batches
          can execute together in the requested order from the repaired
          snapshot. This does not prove a swap will fill, a merchant will
          deliver, or a token transfer will succeed.
        

        

          Cost: the smallest sum of caller-declared positive
          action costs among supported nonce invalidations and single-slot
          lockdown calls. These units are not dollars or gas. A bounded
          exhaustive search returns an explicit limit error rather than
          declaring a large problem impossible.
        

        

          Timing: the entire repair precedes every third-party
          action, with time frozen. Separate transactions are not atomic; an
          attacker can act first or between them. Verify deployment, current
          state and calldata before any real signing.
        

        

          Research: revocation, selective cancellation and
          search algorithms already exist. This experimental implementation
          investigates constrained repair planning and its explanations. No
          first-ever invention, independent security audit or wallet-safety
          guarantee is claimed.
